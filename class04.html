A3績效評估基礎:效率量化 & DMU

核心觀念 績效評估 = 將效率量化。就像溫度在溫度計發明前只有「熱/冷」的感覺,有了溫度計才能說 35 度比 32 度熱。效率若不量化,就無法比較。
  • 評估對象 = DMU(Decision Making Unit,決策單位):小到個人、廠商,大到政府、國家
  • 為什麼叫「決策」單位?要先做了決策(如決定今天工作)才有得評估 — 完全不動就無法評

入門例:學生準備時間與考試成績

學生考試成績準備時間結論
A1001 小時效率高(同產出、投入少)
B10024 小時效率低

  • 人力資源管理:KPI 的設計、KPI 的衡量方法(招募甄選、訓練發展、員工關係、績效評估、薪酬福利)
  • 作業管理:生產力、生產效率(營運策略、商品服務設計、供應鏈與庫存、佈局、品質管理、專案管理)

A4四種績效衡量方法

方法做法缺點
1. 財務比率法同一時期報表兩項目相除(比率分析)靜態分析 — 今年項目除以去年項目沒有意義
2. 平衡計分卡財務/顧客/內部流程/學習成長 四構面 + KPI非財務指標體系難建立;大公司問卷耗時、主觀性強
3. 參數規劃法事先設定函數型態,估計生產/成本函數(經濟學取向)沒有完美函數可刻畫生產過程;邊際報酬遞減
4. 非參數法 = DEA數學線性規劃產生最適權數,結合多投入多產出成綜合指標需要多個個體進行比較(單一 DMU 無法評)

財務比率法的四類指標(簡報詳列)

類別指標
財務結構流動比率=流動資產/流動負債 · 速動比率=(流動資產−存貨−預付費用)/流動負債 · 固定比率=固定資產/股東權益 · 自有資產比率=股東權益/資產總額 · 平均借款利率=利息費用/借款總額
獲利能力營業毛利率 · 營業利潤率 · 稅前利潤率 · 總資產報酬率=(稅後營業淨利+利息費用)/平均資產淨額 · 營業費用率
資產運用總資產週轉率 · 固定資產增加率 · 固定資產週轉率 · 應收帳款週轉率 · 存貨週轉率=銷貨成本/存貨總額
員工效率每員工生產毛額/淨額 · 每員工營業利益 · 每員工稅前利益 · 每一員工配備率=固定資產總額/員工人數
課堂補充:靜態 vs 動態(學術定義) 靜態=各年獨立比較;動態=前一年狀況會影響後一年(有時間鏈結)。跨兩年不一定是動態,可能只是 window(視窗)分析。

A5效率 vs 效能(Efficiency vs Effectiveness)

Peter F. Drucker(現代管理學之父,1909–2005) Efficiency is "do the thing right"(把事做對);Effectiveness is "do the right thing"(做對的事)。
  • 順序:先有效能(定對目標),再談效率(方法)。目標定錯,越有效率越糟糕。
  • Drucker 貢獻:目標管理(MBO)、知識工作者(knowledge worker)概念

四家學術定義(簡報整理)

學者效能效率
Barnard (1938)組織目標的實現組織成員需求的滿足
Hit, Middlemist & Mathis (1986)一定時期內有效實現目標短期內有效利用資源
Mondy 等 (1986)過程產生預期結果的程度投入的質量數量與產出的質量數量之比例關係(← DEA 的核心)
張潤書 (1990)達成目標的程度人力物力財力時間做最妥善分配

  • 生產(Production)= 創造、製造或改進商品服務的過程 ≠ 生產力(Productivity)= Output / Input

全要素 vs 偏要素生產力

定義算例(簡報)
全要素生產力 TFP總產出 / 總投入(全部要素加總)單價 1 元產品 7,000 件 ÷(勞動 1,000+材料 500+管理 1,000)= 2.8。因投入單位不同(人/件/元),需全部換成產值才能相加

發展史

生產邊界(簡報 圖1.4 重繪)

定義 邊界產出 Y* = max{Y | X 能生產 Y}:特定技術下,某定量投入能獲得之最大產出。
邊界投入 X* = min{X | X 能生產 Y}:特定技術下,生產某定量產出所需之最小投入。
圖 1.4 邊界產出與投入(原簡報第 63 頁):A 在邊界內 = 無效率。往 B 走 = 同投入極大化產出(Y*);往 C 走 = 同產出極小化投入(X*)。

CCR 模式(簡報公式 4.3)

Max  TE(i) = (u₁y₁ᵢ + u₂y₂ᵢ + … + u_M y_Mᵢ) / (v₁x₁ᵢ + v₂x₂ᵢ + … + v_K x_Kᵢ)

s.t. 每個 DMU 的「虛擬產出/虛擬投入」比 ≤ 1   (n = 1, 2, …, N)

u = 產出權數、v = 投入權數,由線性規劃自動求出「對受評 DMU 最有利」的權重(即分析各投入產出項的重要性)。

A9ESG / CSR 理論脈絡(簡報第 70–78 頁)

什麼是 ESG?

  • E — Environment 環境保護:氣候變遷、資源使用、污染防治
  • S — Social 社會責任:員工權益、消費者保護、社區發展
  • G — Governance 公司治理:董事會結構、資訊揭露、內控問責

CSR 概念的百年演進

1924
Oliver Sheldon《管理哲學》
將道德因素帶入經營管理,主張企業責任須滿足產業內外關係人利益 — 顛覆「企業責任就是為股東賺錢」。
1953
Howard Bowen《企業的社會責任》
企業有義務滿足社會目標與價值 — 開啟 CSR 概念思辨。
1984
Freeman 利害關係人理論
《Strategic Management: A Stakeholder Approach》— 經營績效不能僅以股東價值極大化判斷,應滿足顧客、員工、供應商、社區、政府等利害關係人價值。內部:董事會/員工/工會;外部:顧客/供應商/股東/債權人/政府/社會大眾。
1991
Carroll CSR 金字塔
四層責任(見下圖)。
1997
John Elkington 三重底線(Triple Bottom Line)
企業永續 = 盈利 + 環境保護 + 社會責任(三重盈餘)同時兼顧。

Carroll(1991)CSR 金字塔(重繪)

慈善責任
自願回饋社會:捐贈、公益
倫理責任
符合利害關係人期望、善盡社會公民責任
法律責任
遵守法律底線,如依法納稅
經濟責任(基礎)
提供社會需要的商品服務、合理獲利回饋投資人

E / S / G 各自的關注面向

面向內容
E 五大面向環境保護(污染控制/能源效率/廢物管理)、氣候變化(碳盤查/溫室氣體/再生能源)、水資源、污染控制(清潔生產)、生物多樣性(永續供應鏈)
S 三大面向員工權益保障(公平薪資/安全環境/健康福利)、消費者權益保護、社區發展(教育/醫療/文化)
G 四大機制董事會治理(ESG 入議程與考核)、管理層治理(ESG 管理體系)、內控與稽核、資訊揭露

核能(低碳選項)能量密度極高、零溫室氣體、土地需求遠小於風光高放射性廢料半衰期數萬年、最終處置困難;溫排水海洋熱污染
生質能碳中和潛力(生長吸碳);廢棄物再利用推動循環經濟開墾雨林農地、排擠糧食生產推升價格;燃燒過濾不全釋放 PM2.5
推動再生能源是應對氣候變遷的必經之路,但絕非「零環境成本」。唯有在「能源轉型」與「生態保育」之間取得平衡,落實回收機制與生態補償,才能實現真正永續的綠色未來。

環境績效重要指標:排放強度(每單位產值/產品排放量)、減量進度(相對基準年降幅)、能源強度、再生能源占比、碳排放效率。

A11老師的研究應用(課堂分享的已發表論文)

論文一:大陸 30 省 CO₂ + 空氣品質(AQI)環境效率

  • 投入:各省勞動力、能源消耗、固定資本(當 carryover 跨期變數 — 固定資產存續期長,像教室學生一直換但教室還在)
  • 產出(好):各省 GDP;產出(壞):CO₂(溫室氣體)、AQI(空污指數)
  • 資料:2014–2016 官方統計;效率 = 1 代表「最少投入、最大經濟收益、最少污染」全都顧到
  • 效率低的省份可再細分:是經濟不行?還是 AQI(有毒氣)還是 CO₂(溫室氣)拖累?→ 對症下藥

論文二:多階段(Multi-stage)DEA — 經濟 × 健康

第一階段(經濟):勞動/資本/能源 → GDP + [AQI、CO₂]
                                        │ 連結項(link)
第二階段(健康):[AQI、CO₂] + 醫療衛生支出 → 出生率(好)
                                          呼吸道疾病、死亡率(壞)
  • 連結項(link)= 上一階段的產出、下一階段的投入(像麵包:種麥→麵粉廠→烘焙,麥子與麵粉就是連結項)
  • 壞產出處理:取倒數或平移,否則電腦誤判「越多越好」
  • 連結項要有確定的因果(污染→不健康是公認,不用驗證;睡眠→成績這種不確定的要先跑統計驗證)
量化研究鐵則 資料一定用官方/權威來源(政府出版品、資料庫)。「你如果資料來源被 question,就很麻煩」— 自蒐資料要先證明有效性。

B4企業價值 EV(Enterprise Value)

定義(簡報第 16 頁) 企業價值 EV = 公司市值 + 負債 − 現金 
企業價值 EV
 ├── 公司市值 ← 股價 ← EPS(每股盈餘)× PE(本益比)
 │                     ├ EPS ← 營收、成本/費用、淨利
 │                     └ PE  ← 產業前景、策略 ★
 └── 淨負債(負債 − 現金)
  • 該追求的是企業價值,不只是 P&L — 「PE 我承認是喊的,但絕對不是亂喊」:根據產業前景、策略規劃、機會成本分析、競爭態勢
  • 配套分析:策略規劃邏輯與機會分析、價值網與競合分析、價值主張與商業模式分析、企業利潤極大化

B5財務模型六大面向

財務模型 = 把企業經濟活動按「價值創造主線」分類、整理、鏈接,再依實際與未來發展做數據預測,評估財務狀況與經營績效。完整模型包含:假設、三大報表、指標分析、估值分析、投資回報測算。

面向檢視重點
1. 負債之成本及償付壓力資金來源與效益;負債成本高低與償付壓力;估列負債的穩健性。「可以舉債經營,但要算承受能力 — 不要跑三點半」
2. 資產之品質評估組成是否符合產業特性?大小與營收規模相當?是否為營運所必需?流通性與變現價值?
現金存款→穩健性;應收帳款存貨→經營效率;長投固資→投資決策
3. 營收及毛利是否健康毛利率與景氣同業相比是否合理;業外收益是否高於本業?成本費用控制反映管理能力;注意非營業收入及異常損失
4. 股東之權益及報酬率股本大小與每股獲利能力;長期資金籌措時機與效率;股利政策與股東投資報酬率
5. 現金控管是否嚴謹現金淨流入量是企業生存之命脈;損益表有獲利不代表有現金流入;不適當之投資是現金流量的殺手
6.(課堂補充)應收/存貨品質應收帳款三年沒收回、存貨比重異常 = 假帳警訊(「我們買公司都先看應收存貨,大陸很多是假帳」)
「看一家公司,先看現金 — 現金是一家公司的元氣。股本三億、現金三億,就知道這些年沒有努力賺錢存錢。」

B7支柱①:透明即時的財務報表

財務報表之於企業,就像體檢表之於人體。三大報表:

報表性質你可以了解
資產負債表某一「時點」的淨資產(財務狀況)財產多少、負債多少、庫存/現金多少
損益表一段「期間」的經營(財務績效)有沒有賺錢、利潤好不好、經營效率
現金流量表一段期間的現金異動資金是否充裕、營業/投資活動資金異動

簡報批註:存貨要控管避免「黑字倒閉」;固定資產決定了就要承擔多年折舊,投資前先以 ROI 試算。資產負債表分析六構面:資產品質、資產配置、長投佈局、潛在負債、負債結構、股東權益。

三大周轉率

  • 固定資產周轉率 = 營業收入/平均固定資產:每 1 元固定資產創造多少銷售。過低 = 資產閒置缺乏生產力
  • 應收帳款周轉率 = 銷貨收入/平均應收帳款:越高越好(收現天數越短);拖越久 → 資金積壓 + 呆帳風險急升
  • 存貨周轉率 = 銷貨成本/平均存貨:越高資本運用效率越高;過低 = 存貨積壓 → 呆滯或跌價

公司201820192020解讀
X海(組裝)19.0418.9018.65資產輕、快週轉

ROA / ROE / 三率

  • ROA =[稅後淨利+利息費用×(1−稅率)]÷ 平均資產總額。簡報例:A、B 公司淨利同為 400,但 A 資產 3,000(ROA 13.3%)、B 資產 700(ROA 57.2%)→ B 優於 A
  • ROE = 稅後淨利 ÷ 平均股東權益:EPS 只反映「賺多少」,ROE 反映「賺多有效率」
  • 三率:毛利率 / 營業利益率 / 淨利率 — 高低反映競爭力;「三利加三率」同時評估獲利質量
  • 本益比 PE = 每股市價 / EPS — 衡量公司便不便宜的工具

透視財務危機(損益表警訊)

  • 每股盈餘品質遠重於高低;盈餘來源是否集中本業
  • 注意「營業損益是否經常性大於營運淨現金流量」(獲利沒現金 = 警訊)
  • 營收逐年大幅下滑或停滯 = 前期財務危機警訊

C2重點提醒(易踩雷)

  1. 效率要先量化才能管理 — 沒數字就只是感覺(溫度計比喻)
  2. 先效能後效率 — 目標定錯,越有效率越慘
  3. DEA 需要比較對象;DMU 越多邊界越準;量體差太多權重會爆
  4. DEAP 檔名要簡單英文、大小寫一致(課堂一半人卡在這)
  5. 徑向效率 1 ≠ 完全效率 — 可能還有 slack(99 分 vs 100 分)
  6. 壞產出(污染)要取倒數/平移,量化資料一定用官方來源
  7. 財務長先懂公司定位(微笑曲線哪一段)再決定財務 focus
  8. 看公司先看現金 — 現金是元氣;獲利 ≠ 現金流入
  9. 周轉率要配產業特性看(台積電 0.9 vs 鴻海 19 都正常)
  10. 財務成本內部化 → 每個 BU 自己管好庫存/應收/固資
  11. 利潤留哪裡要經得起檢驗(BEPS 實質性:風險承擔越重、剩餘利潤越多)
  12. 併購:文化整合是成敗關鍵;資訊不對稱是最大風險;商譽每年減損測試

C330 秒口頭複習

上午(林泰宇):績效評估 = 把效率量化。四種方法裡 DEA 最實用 — 把效率最高的 DMU 連成生產邊界(Farrell 1957 → CCR 1978 固定規模 → BCC 1984 變動規模),邊界上 = 1,邊界內沿徑向改善、再看 slack。DEAP 軟體五步驟跑出效率值 + 學習對象(peer)+ 最適投入產出。應用:ESG 環境效率(CO₂/AQI)、多階段 DEA(連結項)。理論脈絡從 MDGs→SDGs、CSR(Sheldon→Bowen→Freeman→Carroll→Elkington)到再生能源功與過。

下午(王淑玲):前台達集團總財務長 35 年實戰。先當稱職的掌舵者(願景→共識→策略→執行),用微笑曲線定位公司(台積電走附加價值 ROE 33%、鴻海走營收規模 ROE 12.7%),追求企業價值 EV = 市值+負債−現金。財務管理六大支柱:①透明財報(體檢表、三大周轉率、三率)②多維管理報表(產銷雙面 P&L、財務成本內部計價)③最適稅負(Apple 案例、BEPS、TP、大陸追稅 60 億血淚)④資金資本市場(匯兌四支柱、Net Cash Forecast)⑤M&A(婚姻比喻、PPA、商譽減損、文化整合)⑥矩陣式組織。
